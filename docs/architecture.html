24 Mantra Advisor: how the app is built and how one message travels

A chat advisor that runs on free services only. Every message passes through our own server, so each conversation is saved in a database we control and can read later.

Architecture

The browser never talks to the AI directly. It talks to a FastAPI server on Render, which checks the request, finds matching products, calls the AI, and records both sides of the chat in Postgres.

Functional flow of one conversation

Steps 1 to 4 run when the page opens. Steps 5 to 12 run every time the visitor sends a message.

A "New chat" click creates a new session id in the browser. The old conversation stays in the database and in the admin page.

How the sales-agent rules are enforced
